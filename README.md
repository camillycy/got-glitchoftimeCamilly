## Sobre o Projeto

Glitch Of Time é um jogo 2D desenvolvido na Godot Engine como projeto acadêmico. O jogo acompanha dois personagens, Ravi e Celeste, que precisam cooperar para restaurar o equilíbrio do tempo após um colapso temporal que afetou diferentes realidades.

## Principais Funcionalidades

- Controle de dois personagens
- Sistema de diálogos e narrativa
- Inimigos com IA e patrulhamento
- Plataformas e obstáculos
- Boss Fight
- Cutscenes e transições entre fases
- Trilha sonora e efeitos sonoros

## Tecnologias Utilizadas

- Godot Engine 4
- GDScript
- Pixel Art 2D

## Como Executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/camillycy/got-glitchoftimeCamilly
   ```

2. Abra o projeto na Godot Engine 4.

3. Execute a cena principal do jogo.

Projeto desenvolvido como trabalho acadêmico para o último semestre do curso de Análise e Desenvolvimento de Sistemas.
